1. 左侧导航怎么用

左侧边栏把全部功能分成两组。带蓝色高亮的那一项就是你当前所在的页面。

区域在这里做什么
数据集入口页。创建数据集、上传图片或视频、进入标注、发起自动标注、导出数据。
训练用本机算力开始训练、看实时日志和进度、暂停或停止、恢复中断的任务。
模型管理训练产出的模型文件：下载权重、快速测试一张图、比较两个模型、转 ONNX、看评估历史。
智能体四种本地助手模式。用自然语言提问，读证据后回答；要创建任务时必须你点确认才会执行。
日志查看本机后端运行日志的末尾内容，支持按级别和关键词筛选。
设置配置 SAM 模型、智能体的 LLM 连接、切换界面语言。

右上角的「本地模式」徽标表示当前没有连接任何远程服务。

2. 数据集：建立与导入

2.1 创建数据集

在「数据集」页创建数据集时，选择四种任务类型之一。类型决定了画布提供什么标注工具，也决定导出和训练的格式：

detect（目标检测）

画矩形框，标注框的坐标和类别。

segment（分割）

画多边形轮廓；可选 SAM 框选/点选辅助生成多边形建议。

obb（旋转框）

画带角度的框，适合倾斜目标。

classify（分类）

每张图片只选一个类别，不画框。

2.2 导入图片

三条路径，任选其一：

  1. 浏览器上传：用「导入数据集」对话框选图片文件直接上传。
  2. 视频抽帧：同一个对话框里切到「视频文件」，上传 MP4、MOV 或 AVI，指定新数据集名称、任务类型，再设置按 FPS、按时间间隔或按帧间隔抽帧。上传后先预览分辨率、时长和预计帧数，确认后才开始生成帧。
  3. 目录扫描：把图片放进本机 data/imports/ 下的子目录，再在界面里选择该目录扫描导入。服务端只允许访问这个目录，目录外的路径会被拒绝。

2.3 管理 split（训练/验证/测试划分）

每张图片都会被分到 train、val 或 test 三个划分之一，并且这个划分会被固定下来。校验、导出和训练评估用的是同一份划分，不会每次重新随机切分。

  • 在导入时选择初始 split，或选「按连续时间块分配」，把一段连续视频按时间窗口和比例分到不同 split。
  • 数据集页支持批量调整和可复现的自动 split。
  • 重复或高度相似的图片会出只读报告，不会自动删除任何图片。

3. 标注画布操作

从数据集卡片进入某张图片后，画布分三块：中间是图片，右侧是类别和标注列表，顶部是工具和保存按钮。

3.1 通用操作（所有任务类型）

  • 切换图片：按 ← 或 →；也可点右侧图片列表里的缩略图，列表支持按 split 筛选和翻页。
  • 保存：按 Ctrl/⌘ + S，或点右上角「保存标注」。标题旁会显示「未保存修改」或「已保存」。
  • 类别管理：右侧「LABEL CLASSES」区点「+ 新增类别」创建类别并选颜色；点列表中某个类别即可切换为当前绘制类别；每条右侧的垃圾桶图标可删除该类别（有确认提示）。
  • 调整已存标注：右侧「SAVED SHAPES」列出当前图片的全部标注，可以改某条标注的类别，或点垃圾桶删除单条标注。
  • 没有类别时不能开始绘制，界面会提示先新增类别。

3.2 按任务类型标注

类型操作方式
detect选「BBox」工具，在目标上拖拽画框。点框可选中：拖动移动位置，拖四角手柄调整大小。BBox 不支持旋转。
segment选「Polygon」后逐点点击，最后点「完成多边形」。也可用「SAM 框选」拖一个提示框，或「SAM 点选」点一个前景点，让 SAM 返回多边形建议——建议必须你确认后才按普通 polygon 保存。未配置 SAM 模型时，「框选」只会给出明确标注为仅供审阅的矩形建议，不会声称运行了模型推理。
obb在空白处拖拽创建旋转框。点击已有框选中它：拖动移动，四个角点手柄调大小，顶部圆形手柄或角度输入框调旋转角度。保存前编辑器会把框的角点限制在图片范围内。也可用「删除所选 OBB」按钮移除。
classify不画框。在右侧选择一个类别即为这张图片打上类别标签。

4. 缩放与平移

看小目标细节时用这两个能力，它们只改变画面的显示方式，不会改动原图，也不会影响已存标注的坐标——标注始终以归一化坐标存取，与显示缩放完全解耦。

  • 滚轮缩放：在画布上滚动鼠标滚轮即可放大或缩小，范围 0.1x 到 8x。缩放以鼠标指针为锚点，指针指着的位置在缩放过程中保持不动。
  • 抓手平移：工具栏点「抓手」，然后按住左键拖拽即可平移画面。未选中抓手时，左键仍然是绘制语义。
  • 视角复位：切换到另一张图片时，缩放和平移自动复位，不会带上一张图的视角。
  • 当前缩放百分比显示在画布的尺寸信息里。
放大后画框依然准确缩放只作用于显示层，指针坐标会先还原成图片坐标再用于绘制。放大后新画的框，保存并刷新后仍落在原图的正确位置。

5. 导入导出 YOLO / COCO

  • YOLO ZIP：detect、segment、obb 三种任务用 ZIP 导入和导出。
  • YOLO classify：用标准的 train/<类别>/<图片> 目录布局导入和导出。
  • COCO ZIP：detect 和 segment 支持 COCO 格式互导。
  • 不可信的 ZIP 在写入前会检查成员数量、单文件大小、总解压量和压缩比，超限会被拒绝，不会写满磁盘。

6. 数据校验

训练前先跑一次数据集校验。校验会检查标注覆盖率、类别分布、小目标数量、重叠框和类别失衡，并给出提示。请确保 train 和 val 里都至少有一张已标注图片，否则训练任务会被拒绝。

7. 本地训练

  1. 进入「训练」页，新建训练任务。
  2. 选择数据集，以及和数据类任务类型匹配的基础权重（例如 yolov8n.pt、yolo11n-seg.pt、yolo26n-obb.pt）。首次使用命名权重时，Ultralytics 可能下载对应文件。
  3. 选择设备：cpu、mps（Apple Silicon）、单张 CUDA 卡，或多张 CUDA 卡走本地 DDP。
  4. 提交后任务进入本机 FIFO 队列。页面显示实时日志、进度和指标摘要，可随时停止。
  5. 中断的任务可以恢复，也可以从受管的 last.pt 创建继续训练的任务。
训练与自动标注互斥同一时刻本机只会执行其中一个，另一个会排队等待。

训练完成后，best.pt 和 last.pt 会自动登记到受管模型目录。

8. 模型与评估

在「模型」页管理训练产物：

  • 下载权重：下载受管的 PT 文件；也可导出静态 FP32 格式的 ONNX。
  • 快速测试：用持久化的图片跑一次推理，直接看效果。
  • 模型比较：同一个数据集下的两个模型可以并排比较。
  • 评估：对受管 PT 选择 train、val 或 test split 创建后台评估任务。评估在后台运行原生 YOLO val，产出指标、日志、混淆矩阵、PR 曲线和最多 200 个可审阅的错误样本。评估复用图片已固定的 split，不重新随机切分。
  • segment 任务会分别给出 box 和 mask 两组指标与曲线；classify 目前只展示 top-1 / top-5 总体指标。

9. 自动标注

从数据集卡片启动自动标注，用已有模型先标一遍，再人工修正：

  1. 默认跳过已有标注的图片；要重跑需明确关闭跳过选项。
  2. 选择一个受管 PT，类别映射会要求你显式确认——未映射的类别会被跳过，不会按序号猜测。
  3. 调整置信度和 IoU 阈值，可选清理旧标注。
  4. 启动后可看实时进度、日志，并可取消。
自动标注结果必须人工审核生成结果标记为 auto 来源，审核通过后再用于训练。不要直接拿未审的自动标注去训练。

10. 智能体助手

  • 从左侧「智能体」进入综合助手；也可以从数据集卡片、训练或模型页的「询问助手」进入，自动带上对应对象。
  • 四种内置模式：综合、数据集、训练、模型。它们共享配置和执行器，各自限定能读和能申请的工具。
  • 提问：输入问题后按 Ctrl/⌘ + Enter 发送；只做查询时勾选输入框下方的「仅查询」，或直接用快捷提问。
  • 写操作必须你确认：助手要创建训练、评估或自动标注任务时，会先弹出一张待确认卡片，写清对象、参数和预期产物。只有点「确认执行」才会真正提交，提交后本轮结束，不会自动串联下一步。
  • 每轮可以展开看工具证据和推理来源；失败或取消的运行可重试，沿用原来的模式和权限。
  • 需要真实模型回答时，到「设置 → Agent LLM」启用 Provider、填 API Base URL 和模型名、测试连接后保存。未配置时使用本地规则模式，无需密钥即可体验查询和确认流程。
  • 会话历史分页加载，支持按标题和对象 ID 搜索。

11. 设置与日志

  • SAM 设置：配置 SAM 模型、推理设备、推理尺寸，以及未配置模型时的 review-only 回退策略。
  • Agent LLM：配置智能体使用的模型服务。API 密钥只从环境变量或设置页读取，不会出现在任何接口响应里，日志中也会脱敏。
  • 语言：切换界面语言，偏好只保存在当前浏览器本地。
  • 日志：查看本机后端运行日志的末尾内容，支持按尾部行数、级别和内容筛选。日志按 2 MiB 轮转并保留三份备份。

12. 常见问题

现象处理办法
训练或校验报 NumPy 兼容性错误本项目固定 ultralytics==8.4.115 与 NumPy 1.x 基线。在项目 venv 里重装依赖。
后端无法启动确认 YWA_HOST 为 127.0.0.1，然后执行数据库迁移升级到最新版本。
训练任务被拒绝先跑数据集校验，确认 train 和 val 都有已标注图片，且模型系列与任务类型匹配。
首次训练下载不了权重为 Ultralytics 首次下载命名权重提供网络访问，或改用模型库里已有的受管模型。
ONNX 导出失败确认源 PT 在受管模型目录下，并已安装 onnx、onnxruntime、onnxscript 和 onnx_ir，再看任务里的错误信息。
